# 批混剪工作室 v3

视频批量混剪工具，支持片头/片中/片尾拼接、字幕显示、文字/图片水印、背景音乐混合。

## 功能

- 批量混剪：片头 + 片中 + 片尾自动拼接
- 字幕支持：SRT 格式字幕，可调颜色、大小、字体、边距
- 文字水印：支持多行、竖排、可调大小和透明度
- 图片水印：支持 PNG/JPG 水印，7 种位置可选
- 背景音乐：自动混合背景音乐
- 背景素材：支持替换绿色背景（色键抠图）
- 中文界面，操作简单

## 环境要求

- Python 3.10+
- FFmpeg（放到 `ffmpeg/` 目录下，或添加到系统 PATH）

## 使用方法

1. 下载本项目
2. 将 FFmpeg 放到 `ffmpeg/` 目录下（目录结构：`ffmpeg/bin/ffmpeg.exe`）
3. 运行 `启动.bat` 或 `python app.py`

## 素材目录结构

```
素材根目录/
  片头/     (intro)
  片中/     (mid)
  片尾/     (outro)
  背景/     (background)
  字幕/     (subtitle, SRT 格式)
  背景音乐/ (music)
  输出目录/ (output)
```

使用「总扫描」功能会自动识别以上目录。

## 字幕格式

支持 SRT 格式：

```
1
00:00:01,000 --> 00:00:03,000
这是第一行字幕

2
00:00:04,000 --> 00:00:06,000
这是第二行字幕
```
